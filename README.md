# 💼 Job Tracker

Job Tracker is a simple and responsive web application designed to help users organize and track their job applications in one place.

## ✨ Features

- ➕ Add new job applications
- 🏢 Store company and job role details
- 📅 Track application dates
- 📍 Add job location
- 📊 View application statistics
- 🔍 Search applications by company, role, status, or location
- 🗑️ Delete applications
- 💾 Save applications using Local Storage
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 🎯 Project Purpose

This project was created to practice front-end web development and JavaScript concepts while building a useful real-world application.
